🛍️ amazon-product-search-v2

Search Amazon products from Python — no PA API key needed. Powered by curl_cffi browser impersonation + BeautifulSoup4.

Install: pip install amazon-product-search-v2  ·  Import: from amazon_product_search import Amazon

Install Quickstart Parameters Results Pagination Field semantics Errors Tuning Notes

Installation

From PyPI (recommended):

pip install amazon-product-search-v2

From GitHub (developers):

git clone --depth 1 https://github.com/ManojPanda3/amazon-product-search
cd amazon-product-search
pip install -e ".[test]"   # editable + test extras (pytest, coverage)

Requirements: Python 3.9+, beautifulsoup4>=4.11, curl_cffi>=0.13, lxml>=4.9.

Quickstart

from amazon_product_search import Amazon

# Session is reused across searches (keep-alive).
# Use as a context manager to auto-close.
with Amazon() as amazon:
    result = amazon.search("thinkpad", productType="electronics", page=1)

print(result.current_page, "/", result.total_pages)
for prod in result.products:
    print(prod.title, prod.price, prod.currency)
    print(prod.get())  # dict: title/link/review/review_numbers/currency/price/image

Pagination

from amazon_product_search import Amazon
import json

with Amazon() as amazon:
    r1 = amazon.search("thinkpad", productType="electronics", page=1)
    print(f"Page {r1.current_page} of {r1.total_pages} — {len(r1)} products")
    r2 = amazon.search("thinkpad", productType="electronics", page=2)
    print(json.dumps(r2.get(), indent=2))

Iterate all pages:

amazon = Amazon()
page, all_products = 1, []
while True:
    res = amazon.search("laptop", page=page)
    all_products.extend(res.products)
    if res.current_page >= res.total_pages:
        break
    page += 1
print(f"Collected {len(all_products)} across {res.total_pages} pages")
amazon.close()

Field semantics

Parsing never raises on missing markup — fields degrade gracefully.
SituationValue
Field absent from Amazon's HTMLNone (or whole price dict None)
Review count missing, block present0
Price not parseable as a number0.0 (never raises)
Review count suffixes"1.2K" → 1200, M/B supported

Error handling

ErrorCause / fix
ValueError: Error product Name is requiredPass a non-blank productName.
ValueError: Error while geting data from AmazonEvery attempt was blocked or errored. See Anti-bot — retry with Amazon(is_debuging=True) for per-attempt logs, or widen the rotation with Amazon(max_attempts=6).
Empty productsNo match, or Amazon changed markup — check total_pages, try another page.

Session & performance

# Reuse one instance: the HTTP session stays alive (no TLS handshake per search).
# workers is accepted for backward compatibility; extraction is serial.
amazon = Amazon(is_debuging=False, workers=4)
...
amazon.close()  # or: with Amazon() as amazon: ...

Anti-bot transport 🛡️

Amazon blocks scrapers on the TLS/HTTP2 fingerprint, not just headers. A plain requests/httpx call gets a 503 "Sorry! Something went wrong!" page — or a 200 interstitial carrying bm-verify — that parses to zero products. This library impersonates a real browser via curl_cffi, then:

  • detects challenge pages by body markers, not just status code;
  • rotates browser fingerprints across attempts with exponential backoff (blocks follow the fingerprint, not the URL);
  • sends no hand-written User-Agent — one that disagrees with the TLS fingerprint is itself a signal.
# Tune the retry: timeout (s, 20+ for slow links — pages are ~1 MB),
# attempts (capped at the 6 profiles), backoff base (s)
amazon = Amazon(timeout=20, max_attempts=4, backoff=0.4)

Still blocked? No fingerprint trick makes bulk scraping immune — add delays and proxies.

Important notes

  • Rate limiting: heavy concurrent scraping can still get you blocked — add delays/proxies for bulk scraping.
  • ToS: scraping may violate Amazon's ToS — personal/educational use only.
  • Site changes: if Amazon changes markup, selectors are documented in docs/SELECTORS.md with an update checklist.
